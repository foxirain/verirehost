# Roadmap

The public roadmap concerns the generic framework only.

## Implemented

- canonical, content-addressed receipts;
- path-free private artifact binding;
- generic rehosting profiles and JSON schemas;
- fail-closed bounded AArch64 slice execution;
- AArch64 reference-discovery helpers;
- static kernel configuration preflight;
- synthetic unit and CI controls.

## Next framework milestones

- declarative multiple permitted-code intervals;
- typed, target-neutral service-hook interfaces;
- deterministic scheduler and trace event schema using synthetic fixtures;
- receipt comparison and control-matrix reporting;
- portable engine capability discovery;
- stronger schema validation at CLI boundaries.

## Stop conditions

Public work stops before adding any product-specific address map, trust-chain
result, protocol sequence, persistence path, or vulnerability reproduction.
Those belong in a separate private repository and follow its disclosure policy.

Physical-device testing is not an automatic framework milestone and is not
automated by this repository.
